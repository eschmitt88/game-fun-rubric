# input-output-randomness-timing

## Definition

The timing of a random event relative to the player's decision (before = input randomness, after = output randomness) changes felt fairness and satisfaction more than the presence of randomness itself.

## Why it matters here

- **zhang2021effect** — Input randomness hurts satisfaction (p=.024, ηp²=.295, N=18); output randomness no effect. Reverses Burgun's claim.
