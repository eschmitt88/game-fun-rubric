## Demo page content (archived, grapefrukt.com/f/games/juicy-breakout/, 2012-05-30 capture)

The playable Flash demo page itself (archived, since it 404s live today)
contains only this text around the embedded .swf:

```
juicy-breakout
Press ESC to bring up menu. 2 resets all effects. Enter enables all effects.
Game by Martin Jonasson & Petri Purho. Music and sounds by Niklas Ström.
http://prototyprally.com/juice-it-or-loose-it/
http://www.youtube.com/watch?v=Fy0aCDmgnxg
https://github.com/grapefrukt/juicy-breakout
```

This confirms the demo shipped as a **live toggle**: press Enter to turn
all juice effects on, press 2 to reset/strip them back to the bare
mechanical Breakout clone — i.e. the artifact itself is built to let a
player A/B the juiced vs. unjuiced version of the identical game logic.
